# Высоконагруженная платформа визуального поиска и сохранения идей Pinterest

Курсовая работа по курсу «Проектирование высоконагруженных систем»

## 1. Тема и целевая аудитория

**Тема**

Высоконагруженная платформа визуального поиска и сохранения идей (Pinterest). Ближайший аналог - Pinterest

Pinterest представляет собой визуальную поисковую платформу, которая позволяет пользователям искать, организовывать и сохранять идеи в различных тематических областях. Сервис сочетает в себе функции социальной сети, визуального поиска и системы закладок. Пользователи создают доски, на которых сохраняют пины - изображения, видео или ссылки на внешние ресурсы

**Целевая аудитория:**

Основная аудитория сервиса состоит из следующих групп:

- Пользователи - люди, которые ищут вдохновение, сохраняют идеи, создают доски и планируют различные активности;

- Бизнес-пользователи и бренды - компании, которые публикуют контент, продвигают продукты и взаимодействуют с аудиторией через рекламные инструменты;

В качестве ориентира по масштабу используется оригинальный Pinterest. По итогам 2025 года глобальная месячная активная аудитория платформы достигла 578 млн человек, что на 12% больше по сравнению с предыдущим годом [[1]](https://venuelabs.com/ru/pinterest-statistics/). В первом квартале 2026 года показатель вырос до 640 млн месячных активных пользователей [[2]](https://digital-digest.ru/ayditoriia-pinterest-vyrosla-do-640-mln-polzovatelei-itogi-vtorogo-kvartala-2026-goda/?ysclid=mtuc377c4s984092196), [[4]](https://mybusiness.by/2026/tpost/pinterest-v-2026-prodazhi).География — глобальная, с сильным присутствием в США и Канаде (102 млн MAU), а также в остальном мире (367 млн MAU) [[1]](https://venuelabs.com/ru/pinterest-statistics/)

Портрет аудитории [[1]](https://venuelabs.com/ru/pinterest-statistics/):

- Около 70% пользователей составляют женщины;

- Большую часть аудитории составляют люди в возрасте 25 - 34 лет;

**Функционал MVP [[3]](https://rudesignshop.ru/blog/arhitektura-pinterest/?utm_referrer=https%3A%2F%2Fyandex.ru%2F):**

1) Регистрация и авторизация пользователей;
2) Создание, редактирование и удаление пинов - загрузка изображений и видео с указанием описания, ссылки и тематических категорий;
3) Создание и управление досками - пользователи могут создавать доски для организации пинов по темам;
4) Сохранение пина на доску - ключевое действие, при котором пользователь добавляет чужой или свой пин в одну из своих досок;
5) Визуальный и текстовый поиск - поиск пинов по ключевым словам, категориям, а также поиск по изображению;
6) Просмотр ленты рекомендаций - персонализированная лента на основе интересов пользователя и сохраненных пинов;
7) Лайк пинов - пользователь может отметить определенный пин, как понравившейся;

**Ключевые продуктовые решения:**

- Сервис позиционируется как визуальная поисковая платформа, а не просто социальная сеть;

- Контент организуется по принципу досок и пинов. Каждый пин содержит изображение (или видео), описание и опциональную ссылку на внешний ресурс;

- Персонализация - лента рекомендаций и результаты поиска строятся на основе сохраненных пинов, взаимодействий и поведенческих паттернов пользователя;

- Визуальный поиск - ключевое конкурентное преимущество: пользователь может найти похожие пины по загруженному изображению;

- Мобильный приоритет - значительная часть пользователей заходит через мобильные устройства, что требует адаптивного дизайна;

## 2. Расчет нагрузки

**Исходные данные:**

- Глобальная месячная аудитория - 640 млн MAU
- Общее количество пинов - 300 млрд
- Общее количество досок - 15 млрд
- Число поисковых запросов в месяц - 80 млрд
- Внешних кликов в месяц - 1,7 млрд
- Средний размер изображения (с учетом сжатия) - 500 Кб на пин

**Расчет дневной аудитории (DAU):**

По данным Blank of America есть соотношение: DAU/MAU = 14%, характерное для сервисов ежемесячной моделью использования. Соответсвенно для pinterest дневная аудитория составляет 89,6 млн DAU

**Расчет среднего размера хранилища:**

- Среднее число пинов на пользователя (кол-во пинов / месячная аудитория): 300 млрд / 640 млн = 468,8 пинов 

- Средний объем хранилища зображений на пользователя (среднее кол-во пинов * средний размер изображения): 468,8 * 500 Кб = 0,229 Гб

**Расчёт среднего количества действий пользователя в день:**

- Поисковые запросы (среднее числов поисковых запросов в месяц/ 30 / месячная аудитория): 80 млрд / 30 дней / 640 млн MAU = 4,2 поиска на MAU в день => среднее количество запросов в день - 31

- Сохранение пинов: 5 - 10 сохранений на DAU в день

- Лайк пина: 10 - 20 лайков на DAU в день

- Создание пина: 0,05-0,1 создание на DAU в день
